📌 주암민원 자동진행

이 버튼(북마클릿)은 브라우저 보안상 사이트가 대신 추가해 줄 수 없어요. 아래 둘 중 편한 방법으로 한 번만 등록하면 됩니다. 이후 발사기·국민신문고 어느 화면에서 눌러도 알아서 동작합니다.

📌 주암민원 자동진행 (← 북마크바로 끌어다 놓기)
드래그가 안 되면 — 손으로 등록하기 (1분)
  1. 위 “📋 코드 복사”를 누릅니다.
  2. 아무 페이지에서나 Ctrl+D(Mac은 ⌘D) → 북마크를 저장합니다.
  3. 북마크바에서 방금 만든 북마크를 마우스 오른쪽 클릭 → 수정.
  4. 이름은 주암민원 자동진행, URL 칸을 지우고 복사한 코드를 붙여넣기 → 저장.
  5. 끝. 이제 그 북마크를 누르면 동작합니다.

Chrome·Edge·Whale·Firefox 모두 같은 방식입니다. 모바일은 북마클릿이 잘 안 되니 발사기의 복사·붙여넣기를 쓰세요.

혼자 할 때

  1. 민원 발사기에서 나만의 사연을 한 문장 이상 입력합니다.
  2. 북마크를 누르면 6건이 준비되고 국민신문고로 이동합니다.
  3. 로그인 → 민원 › 일반민원 › 민원신청 화면까지 들어갑니다.
  4. 그 화면에서 북마크를 누르면 제목·본문(같은 화면에 처리기관 칸이 있으면 기관까지) 채워집니다. 화면 오른쪽 아래 진행 표시(예: 2/6)를 보고 다음 할 일을 확인하세요.
  5. 처리기관이 다음 화면이면 “다음”을 누른 뒤 그 화면에서 북마크를 한 번 더 누릅니다.
  6. 검색결과 목록에서 해당 기관을 직접 선택 → 공개여부 확인 → 제출.
  7. 제출 후 다음 민원신청 화면에서 북마크를 반복합니다. (6곳까지)

한 컴퓨터로 여러 명이 할 때

한 사람씩 “발사기에서 사연 입력 → 북마크 클릭 → 국민신문고에서 첫 클릭”까지 끝내고 다음 사람이 시작하세요.
첫 클릭 이후에는 그 창(탭)이 독립적으로 진행돼서 다른 사람과 섞이지 않습니다.
가능하면 사람마다 다른 창(또는 다른 기기)을 쓰면 가장 안전합니다.

자동 제출은 하지 않습니다. 매번 제목·본문·처리기관·공개여부를 직접 확인하고 본인이 제출하세요. 가족이 각자 본인 계정으로 참여하는 용도입니다. 발사기에서 북마크를 다시 누르면 순서가 LH부터 새로 시작됩니다.

v6.1 변경: 처리기관 칸이 자동 입력되지 않던 문제를 보완했습니다. 이제 기관 차례가 되면 기관명이 클립보드에 자동 복사되므로, 자동 입력이 안 되면 처리기관 검색창을 클릭해 붙여넣기(Ctrl+V) → 검색 → 선택하면 됩니다. 이전에 북마크를 등록한 분은 지워졌다 다시 등록(재드래그 또는 코드 재복사)해야 새 동작이 적용됩니다.
