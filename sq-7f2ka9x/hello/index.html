🚀 과천 주암 데이터센터 대응 민원·의견서 도우미

LH·국토교통부·과천시·한국전력·과천소방서·한국부동산원 민원(국민신문고)을 이 페이지 하나로 준비할 수 있습니다. 나만의 사연을 반드시 넣어야 매번 다른 문장으로 생성됩니다.

  1. ① 먼저 보라색 상자에서 나만의 사연을 적어주세요 (필수). 사연이 서로 달라야 민원이 스팸으로 묶이지 않습니다.
  2. ② 민원 넣을 기관 탭을 선택하고, 생성된 제목·본문을 꼭 한 번 읽어보세요.
  3. ③ "본문 복사하고 국민신문고 열기" 버튼을 누르면 본문이 복사되고 국민신문고가 새 창으로 열립니다. 본인 계정으로 로그인 → 상단 "민원 → 일반민원 → 민원신청"으로 이동하세요.
  4. ④ 국민신문고 내용란에 붙여넣기 → 이 페이지로 돌아와 "제목만 복사" → 국민신문고 제목란에 붙여넣기 → 제출.
  5. ⑤ 제출 후 이 페이지의 "다음 기관으로" 버튼을 눌러 나머지 기관도 6곳 모두 반복하세요.
⚠️ 이 페이지는 민원을 대신 접수하지 않습니다. 국민신문고에 본인이 로그인하여 직접 제출해야 최종 접수됩니다.

복사·붙여넣기가 번거로우면, 본인 브라우저에서 본인이 검토한 내용을 국민신문고 민원신청 폼에 한 번에 채워주는 북마클릿을 쓸 수 있습니다. 자동 제출은 하지 않으며, 처리기관·공개여부 선택과 최종 제출은 본인이 직접 합니다.

1) 설치 (최초 1회) — 아래 버튼을 브라우저 북마크바로 드래그하세요. (모바일은 지원이 제한적입니다)

📌 주암민원 자동채우기

2) 사용

  1. 기관을 고르고 사연을 넣은 뒤, 아래 "이 민원 자동채우기로 넘기기"를 누르면 국민신문고가 같은 탭에서 열립니다.
  2. 로그인 → 민원 → 일반민원 → 민원신청 폼까지 이동합니다.
  3. 북마크바의 "주암민원 자동채우기"를 누르면 제목·본문이 채워집니다. 내용을 반드시 확인하고 나머지 항목을 채워 제출하세요.

⚠️ 국민신문고 화면이 개편되면 자동 채우기가 동작하지 않을 수 있습니다. 그럴 땐 위쪽의 복사·붙여넣기 방식을 그대로 쓰시면 됩니다. 자동 채우기가 제목·본문 칸을 잘못 찾으면, 채워진 내용을 지우고 수동으로 붙여넣어 주세요.
